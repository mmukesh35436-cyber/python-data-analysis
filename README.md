# Python Data Analysis Project

A beginner-friendly sales data analysis project built using Python, Pandas, NumPy, Matplotlib, and Seaborn.

 Project Objective

The objective of this project is to analyze sales data, identify important patterns, compare product and regional performance, and generate useful business insights from the data.

# Key Questions

- Which products generate the highest sales?
- Which region performs best?
- How does quantity sold affect sales?
- Which products are the top performers?
- What business recommendations can be made from the analysis?

 # Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Exploratory Data Analysis (EDA)

 # Analysis Performed

- Data creation and understanding
- Data type analysis
- Missing value detection
- Duplicate value detection
- Statistical analysis
- Category-wise sales analysis
- Region-wise sales analysis
- Product-wise sales analysis
- Quantity vs Sales analysis
- Sales distribution analysis
- Correlation analysis
- Correlation heatmap
- Business insights and recommendations

# Key Findings

The analysis identified Laptop, Monitor, and Keyboard as the top three products based on total sales.

The project also analyzed regional performance and the relationship between quantity sold, unit price, and total sales.

# Business Recommendations

- Focus marketing efforts on high-performing products.
- Maintain sufficient inventory for popular products.
- Analyze low-performing products for pricing and promotional opportunities.
- Improve sales strategies in weaker-performing regions.
- Use sales data regularly to support data-driven business decisions.
